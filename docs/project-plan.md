# Project Plan — Vithaya Chanthasy Portfolio

## 1. Overview

A premium, minimal personal portfolio for **Chanthasy Vithaya (Vithaya
Chanthasy)**, a marketing communications professional with a dual technical and
marketing background, based in Vientiane Capital, Laos. The site positions
Vithaya as a strategic MarCom specialist who pairs marketing strategy with a
genuine understanding of technology and daily, human-reviewed AI workflows.

- **Project name:** vithaya-portfolio
- **Type:** Single-person professional portfolio
- **Tech stack:** Next.js 16 (App Router), React 19, Tailwind CSS v4, TypeScript
- **Design language:** Red / White / Gray premium minimal (see `design-system.md`)
- **Status:** Content populated from official CV.
